# 核心规则第三轮复盘与检索流程回归

本轮显示，真实检索、原文可回查与完成具体预测，是需要分别检查的三件事。按预测前固定的严格口径，六个具体主结果均未明确回答；两项方向判断与书内记述相符。这不能换算成“0%准确率”，也不能把少量方向相符写成整体预测能力提高。

R3使用六个书中事件，先固定匿名输入、私有参考和评分口径，再由Astra以xhigh完成预测，结束后封存。运行基线为已发布的[0.7.0-alpha.3](https://github.com/zhishengyk/liuyao/releases/tag/v0.7.0-alpha.3)，对应提交`2bfd8e0`；[语料快照](https://github.com/zhishengyk/liuyao/releases/tag/corpus-2026-09-12)指纹为`e105bcde…`。本复盘不改原预测、选例或评分目标。

| 例 | 预先选定的可核项 | 严格结果与限度 |
| --- | --- | --- |
| 01 | 后续生死 | 明确弃断生死；“恢复不顺”的不利方向相符。 |
| 02 | 当时关系去留 | 只断欠稳、有阻，未判断分离或对象离开。 |
| 03 | 本次分娩发生 | “仍有出生条件”没有选定实际分娩；性别、产时也未答。 |
| 04 | 实施摆摊后的盈亏 | “难有稳定利润、破耗风险”未明确选择负收益。 |
| 05 | 是否接受对方条件 | 只断“我方有利”，未回答是否接受条件。 |
| 06 | 后续实际改善 | “有恢复希望”未选定改善发生；恢复方向偏吉相符。 |

另有七项时间、八项细节均属弃断。这些是从反馈中提前固定的核验维度，并不表示输入的泛问“测病”“测婚”已明确要求生死、分手等子目标。病程、病情轻重、婚姻状态、孕周等未给出，很多保留有合理原因。需要如实报告的是具体结果回答不足，不能把谨慎等同算错，也不能把风险、希望或条件成立升级为事件命中。分娩发生本身还是低门槛目标，不能替代性别、时间与安危的检验。

调用审计核实了54次真实MCP调用：排盘6次、检索23次、原文回查25次，错误0次。最终引用的24个不同证据ID均实际返回并完成原文回查，没有虚构引用或只列ID而未读取的情况。五个案例返回中省略了`structured_case`，原因是内容预算；其原文仍完整返回，必要上下文也未缺失。结构化副本省略不能写成“没读到原文”。这些检查证明调用链可追溯，不证明规则推断必然正确。

规则复核发现一处明确的论证缺项：03的检索首项已返回`zengshan_pingshi_dxj-l8978-tomb-break-images`，其中写“测生育子孙墓库月破而易生”。预测却主要把世爻戌土月破解释为母体弱、产程有阻，没有解释同一戌土作为子孙墓库被冲开的条件为何不采用，也未回查该条。应补的是相反依据与适用条件的核对；原作者的“一定顺产”只是断语，实际反馈并未确认生产方式，不能据此判模型产程判断错误。

其他问题有不同程度：01“反复”缺少满足条件的引文；02未充分展开财临日与月克、暗动冲克之间的取舍；05“有利处理”属于综合推断，原文并未直接保证该结果。04和06未发现实质性规则适用错误；不追加事故、具体器官、性别或日期，也不能自动算作漏用规则。

还发现一条来源角色错误：`zengshan_buyi.manual.L04586C0000.case`把“或曰：子孙化退神，何其用药亦效？”这一报验后的教学问答放入已知背景。本次解释者回查了全文，未将它移植为待测背景，该归属已在alpha.4修正：教学设问移回事后分析，原文、盘面和反馈资格均保持不变。

23次BM25检索的实测P50为28.69毫秒，P95为337.68毫秒。这是工具调用墙钟延迟，排除初始化及模型阅读、思考；不是CPU独占计时或压力测试，不能代表各种机器、负载下的性能。

书内反馈也有边界：02和05是作者总括式“应验”，缺少独立后访细节；接受对方条件不能验证法院胜败。06的短期改善不能证明某种治疗导致好转，更不是根治保证。其余书中记述同样不构成现实独立验证。本轮没有支持总体准确率提高的对照证据。

## 8问检索流程：能纠偏，仍有直接匹配缺口

这项测试只找参考案例，不排盘或预测。使用alpha.3冻结库，先按完整原问、不预设事项过滤作一次固定首查（最多5条、14,000字符）；随后每题总共最多3次搜索、4次原文回查。它检验受控首查后的纠偏过程，不能代表所有正常使用方式。

实际完成31次MCP调用：20次搜索、11次原文回查，均成功。8次首查各返回2条，未形成直接匹配；同时有53–56条候补受字符预算影响而未返回。这个现象不能换算成全库召回率，也不能把调用次数限制误作账户额度不足。

| 原问类型 | 评审结果 |
| --- | --- |
| 指定医院的信息岗位录用 | 改写并筛选后找到求职录用问类参考，通过。 |
| 追回已经借出的钱 | 保持债权人回款方向，通过。 |
| 向亲戚借入周转款 | 保持借入方向，通过。 |
| 教师能否留在原学校任教 | 三次检索内未找到直接匹配；没有用班主任职责变化替代学校任职是否保留。 |
| 女儿能否被学校录取 | 找到“某女测女儿考大学”的升学参考，通过；学校层次及指定院校差异仍保留。 |
| 餐馆能否招到某位厨师 | 仅部分相关：找到邀请人管理公司的“可行否”例，未充分区分能否招来与方案是否适宜，不列完整通过。 |
| 丢失手表能否找回 | 找到失物回收问类参考，通过。 |
| 既有资金未来花到何处 | 三次检索内未找到直接匹配；没有换成找失物、追回欠款或交货问题。 |

因此，5题满足冻结的参考标准，1题只有部分目标相关，2题在限定搜索次数内没有匹配，不能计算“检索准确率=5/8”。独立核对了44条候选原问及8条最终引用，参数、引文、证据ID和行列均与日志相符，没有具体错引或“精准同例”虚称。后两题未找到不证明全库没有相关理论或全文材料；本测试限定了case及initial范围，没有穷尽其他检索方式。静态topics表替代了可选目录调用，这项执行适配已单列。

## alpha.4修正与已见案例回归

alpha.4修正上述教学问答归属，并把相反证据核对写成明确步骤：对已返回且可能适用的相反或例外规则，回查全文及共享上下文，对照原文条件与已知事实，说明采用或排除理由；未解分歧保留，未给条件不得补造。没有把本例答案或特定卦象定式写进指南。

随后只用已见的生育例执行CR-01。13次真实调用（排盘1、检索4、原文8）中，模型召回并阅读全文核对了相关相反规则，区分一般世爻月破、生育墓破取象与常规真入墓的条件，不再仅凭月破和伏藏判断生产偏凶。它仍保留产程、母子安危及具体应期的不确定。五项预测前冻结的流程判据均通过，未发现新的实质性曲解。

这是一条已见案例的流程修正，不是新增盲测准确率，更不能据此保证其他案例也会正确。R3与IR8仍保留alpha.3的原始输入、记录和结果；CR-01使用alpha.4及r2语料，未改旧结果。两版语料的规则、案例原文、盘面和数量一致，r2只改变一段教学问答的角色及初始检索内容。

当前六书已完成切片覆盖：1,923条规则、1,930盘案例；其中1,328盘有可核对的书内反馈，602盘为噪音归档，反馈资格待审核为0。在1,328盘中，1,017盘通过绑定的来源盘审核，311盘仍未完成该项核对；有反馈与盘面可作结构证据是不同条件。覆盖完整不等于每条标注无误，原始Word缺损、尚未确认的重刊关系及理论适用分歧仍有边界。

当前不能把端到端问题简单归为“书不够”。可确认的环节包括来源角色错误、无筛选关键词的题意偏离、细分问类匹配不足、模型未核对已返回的相反规则，以及输出未达到可核验的具体粒度。向量检索可作为表达差异的候选召回方式，但不会自动修正这些源事实和推理问题；本轮没有提供向量方案提高总体预测准确率的证据。
