# 象法目录与场景索引

日期：2026-09-10。状态：0.5.0已实现并重建数据库。根据用户提供的《六爻象法进阶》上下册PDF修复目录，原始OCR正文保持不变。

## 原书目录与场景

象法不增加“姻缘／学业／健康”等事项分类。沿用`册 → 章 → 节（如有）→ 原文编号用法（如有）`，用实际场景和关键爻线索找适用论述及案例。

完整目录见[PDF核对目录](六爻象法进阶目录.md)，机器清单见[data/xiangfa_outline.json](../data/xiangfa_outline.json)。两册共119个目录条目，加2个册节点，包含序言等导航条目。序言、目录残文和广告不进入象法正文召回。

上册分为六神之象、组合之象、长生十二宫之象；下册从三刑之象开始，依次为伏神之象、旬空之象、卦之反吟、进退位之象、隔山化爻、六害之象、卦象的参考意义。

例如`六神之象 → 朱雀 → 文书，信息`对应上册PDF第66页的用法，以及其后的论文送审等案例。“材料审核”“信息传递”“论文送审”等短语是依据原文形成的检索提示，不是新的事项分类，也不是引用原文。

## 数据组织

- `outline_nodes`保存目录ID、父节点、顺序、完整路径、PDF核对标题、原OCR锚点、原文范围、目录印刷页和正文PDF页。
- `evidence_outline`关联知识块／卦例与其目录及祖先节点，可以按整章、某节或单个用法限定范围。
- 场景提示为开放短语，来源标为`source_paraphrase`，与目录路径一起加入全文索引。案例自身的作者分析与反馈仍由原有字段保存，不作为场景短语自动生成的输入。
- 同一条证据返回`outline.path`、`intro_refs`、`related_cases`，便于查看目录上下文和继续寻找同一用法的案例。

原始OCR正文未修改，PDF校对标题在独立目录清单中保存。建库时核对OCR哈希与正文锚点，目录元数据参与语料版本哈希。PDF文件及PDF处理工具不进入运行依赖；发布包中的SQLite已经包含目录及关联数据。

## MCP使用

现在提供四个只读工具：`build_chart`、`get_outline`、`search_knowledge`、`get_source`。

```python
# 查看可用书籍，再向下查看六神之象的节目录。
get_outline()
get_outline(parent_id="xf_shang_c01")

# 目录不确定时，直接跨章节查场景。
search_knowledge(query="材料审核", method="xiangfa", limit=5)

# 已定位到朱雀节时，在该节及其后代范围内查询。
search_knowledge(query="材料审核", method="xiangfa",
                 outline_ids=["xf_shang_c01_s02"], limit=5)

# 空查询可浏览该用法的关联案例。
search_knowledge(query="", kind="case", method="xiangfa",
                 outline_ids=["xf_shang_c01_s02_u03"], limit=3)

# 目录节点同样支持原文分页读取。
get_source(evidence_id="xf_shang_c01_s02_u03", max_chars=10000)
```

示例数量仅演示参数。实际数量由AI根据证据缺口和上下文预算主动选择。

`get_outline`不传参数列册节点；传`source_id`列该册章目，传`parent_id`列直接子节点。支持`limit`和`offset`分页。目录本身不代表规则已经满足。

`method="xiangfa"`时不自动推测事项大类，也不应用`topic`过滤或排序；它按场景、目录范围和已知盘面条件检索。其他模式仍保留原有事项过滤行为，完整的理法大类／小类体系不是本次新增功能。

`get_source`保持原文`text`不变，另在预算内补充`outline_context`中的章／节／用法导语。预算不足的内容列在`outline_context_omitted`，可按其中节点ID另行读取。关联案例过多时，使用目录范围查询并去重补查。

## 使用边界与验证

AI应先看已知场景及关键爻，再选择六神、伏神、旬空等线索；不能因为盘中有某个六神就检索整节并套用象义。原文中的条件、例外和参考范围要一起阅读。

本次没有新增所有三刑、长生十二宫、反吟或隔山化爻组合的自动判定，也没有启用向量模型。相关知识仍可按目录和场景查询，但不能声称其条件已由排盘程序全部验证。

自动测试覆盖PDF目录映射、所有知识块的目录边界与关联、原文不被纠字覆盖、场景召回、象法跨事项检索、目录后代筛选、分页、去重及上下文预算。发布协议测试也会调用目录工具、场景检索和导语回查。
