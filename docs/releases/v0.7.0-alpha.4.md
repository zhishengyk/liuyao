# 0.7.0-alpha.4 相反证据核对与事后问答归属修正

本次更新强化助手的证据核对流程：已返回且可能适用于当前盘面的相反规则或例外，必须回查全文和共享上下文，逐项核对适用条件，并说明采纳或排除依据。重要分歧未解决时保留分歧，不为目标结论补造条件；原有停止条件和不强迫猜测的要求保留，不规定每题反例数量。

语料仅修正一条已确认书例的角色归属：把报验后的教学问答从最初已知背景移回事后分析；原文、盘面和反馈资格保持不变。该修正已通过严格建库，core以新文件名和SHA-256固定。运行功能不作改动。

本次回归用于核对指南约束、语料角色和安装链路，不是新增预测准确率评估，也不表示已知裸查询相关性缺口已解决。

六例书例复现、8问检索流程和单例已见回归均已完成。回归显示该例已处理相关相反规则；这不等于预测准确率提高。逐项结果和限制见[完整复盘](https://github.com/zhishengyk/liuyao/blob/main/docs/核心规则第三轮复盘.md)。
