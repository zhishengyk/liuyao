# v1.2.0-rc.1 Preview

这是生产断卦链路与评测链路分离的预览版本，供安装验证，不替代当前稳定版。

## 主要变化

- 生产 Prompt 改为七步预测流程，只保留流程、领域入口和规则 evidence ID。
- 全局流程加入问题边界、动静作用、元忌条件链、领域语义、理象分工和应期边界；15 个领域入口加入最低知识、固定基础证据及四组查询模板。
- 不再把整段历史案例、作者判断和事后结果自动写入生产 Prompt。
- 生产 MCP 移除 `case_text_scope=full`；案例检索和案例原文入口只返回事前问题、事前背景、盘面与机械特征。
- 新增通用 `check_update` 工具，从 GitHub Releases 返回新版本、wheel 和 `uvx` 启动命令，不依赖特定 MCP 客户端。
- 删除生产插件中的盲测评分 Skill，评测材料继续留在隔离开发环境。
- `competition` 成为独立一级领域，旧 `affairs/competition` 在建库时迁移。
- 恢复固定六书语料并重新建库：1,923 条规则、1,930 个案例，质量分布为 eligible 1,325 / noise 603 / pending 2。

## 验证

- 完整测试：390 passed / 2 skipped / 1 xfailed。
- MCP stdio、生产案例泄漏边界、Prompt 生成、六书流程证据覆盖及 release wheel 构建均通过。

这是 preview。请在新任务中安装并确认 MCP 工具注册、案例安全视图和实际断卦流程后，再决定是否提升为稳定版。
