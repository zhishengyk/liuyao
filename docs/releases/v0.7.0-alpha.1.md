# 六爻助手 0.7.0-alpha.1

本次为语料重建预发布。默认入库改为编译人工切片、原文跨度和审核证据，停止把旧自动 OCR 切片直接视为可用案例。六书覆盖尚未完成，稳定版仍为 v0.6.7。

## 本次变化

- 统一三本 PDF 的 811 页来源文本；校订页、案例、原文回查和索引采用同一文本及哈希。
- 人工区分原问、起卦信息、作者分析、实际反馈和事后补充背景；保留一事多卦的关系。
- 案例资格分为 eligible、noise、pending。只有原问存在对应实际反馈的 eligible 案例进入有效检索；噪音和待审案例保留原文。反馈明确而作者断错的案例继续保留为反例。
- 盘面审核与反馈资格分开。独立盘面审计尚未绑定的案例保持 not_run，不能通过有效盘面筛选。
- 修复第 145 页旧 OCR 与校订盘面不同步、作者筛选元数据为空、规则排除范围过宽的问题；补充原文明确取用的可回查标注。
- 默认使用本地 BM25，不需要下载向量模型或运行神经重排。

## 本次冻结数据库

六份来源，989 条规则、945 条卦例记录（880 个案例单元、867 个事件组）。案例资格为 190 条 eligible、146 条 noise、609 条 pending；全文索引共 1,179 条，包含 989 条规则和 190 条 eligible 案例，噪音及待审案例索引为零。

190 条 eligible 中，92 条已绑定独立盘面审核，98 条尚待审核；后者不代表已发现错误。三本原生文本的 609 条案例尚未完成新反馈资格复审，暂不进入有效案例检索。

## 验证与限制

本地新的手切、原文回查、规则引用、排盘及打包相关检查 123 项通过，真实 MCP 的 8 组检查通过。完整旧测试套件本地结果为 186 通过、26 失败、2 跳过；失败项包含旧自动解析器、旧 ID、目录合同及尚未覆盖的检索场景，迁移未完成。预发布 CI 强制新的语料合同及隔离发行包检查通过，并保留完整套件报告；稳定发布仍要求完整套件通过。

独立 Astra xhigh 核心规则试验实际完成 75 次 MCP 调用，未据此宣称预测准确率提升。采用严格反馈资格后，原试验多例应列为噪音，不能汇总命中率。细节见[核心规则首轮盲测评估](https://github.com/zhishengyk/liuyao/blob/v0.7.0-alpha.1/docs/核心规则首轮盲测评估.md)。后续将先固定合格样本，再进行独立预测和评分。

原 Word 文件尚未取得，转换文本中缺失的卦图符号保留未知。新增切片及审核继续进行，本版本不代表六书重建完成。
