# 六爻助手 0.7.0-alpha.2

源码与语料分离：原先Git中的约120MB Markdown资料和约33MB数据、审计文件改为Release压缩包。当前源码目录约1.2MB，`data` 中仅保留语料版本、下载地址和SHA-256清单。旧Git历史和旧标签保留，本次精简新的源码目录及Source code下载包。

## 语料获取

- [重建语料包](https://github.com/zhishengyk/liuyao/releases/download/v0.7.0-alpha.1/liuyao-corpus-0.7.0-alpha.1.zip)：约5.4MB，包含当前数据库所需的508个来源、切片和审核文件。
- [其余资料及历史审计归档](https://github.com/zhishengyk/liuyao/releases/download/v0.7.0-alpha.1/liuyao-reference-archive-2026-09-11.zip)：约45MB，包含其余1877个文件。与重建包合用可恢复完整2385个资料文件。
- 开发时先运行 `python scripts/prepare_corpus.py`。脚本核对锁定的SHA-256，使用本地缓存，并拒绝覆盖人工修改过的资料。加 `--include-reference` 可恢复完整归档。
- 普通插件用户仍使用发行包内的SQLite，不需要下载这些重建资料。

已验证完整2385文件逐字节恢复，以及恢复后18张数据库表的逻辑内容一致；校订记录的本机路径随恢复目录变化。冷缓存联网下载也通过。相关恢复、语料、排盘及打包检查共126项通过。

本版本沿用alpha.1的冻结语料：989条规则、945条卦例记录；190条通过反馈资格审核，其中92条盘面已独立核对，97条待核对，1条原书缺盘。六书完整覆盖、其余盘面复核和端到端评测仍在继续。完整旧测试套件仍有26项待迁移或覆盖缺口；本预发布不宣称全套测试通过或预测准确率提高。
