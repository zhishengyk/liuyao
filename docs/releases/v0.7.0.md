# 0.7.0 正式版

由0.7.0-alpha.4升级发布，沿用其检索实现、相反证据核对指南和固定的r2语料。程序、插件及安装命令统一使用0.7.0；发行包新增正式版Windows安装入口 `install.ps1`。

六书已完成手动切片覆盖：1,923条规则、1,930次起卦记录、1,823个案例单元。1,328条案例记录具备书内反馈资格，602条噪音记录排除出案例检索；盘面核对状态单独保留。源码与语料分离，语料继续由Release压缩包及Git中的SHA-256清单固定，普通用户使用包内预建SQLite。

正式发布要求严格全书覆盖建库、完整测试套件、独立wheel安装自检与缓存离线检查，随后从实际Release下载地址验证插件启动。已知的无筛选求职排序缺口仍以xfail记录，不计作测试通过。

正式版标签不表示预测准确率已经改善。已完成的书例复现、8问检索流程与单例已见回归，以及盘面未核对等限制，见[完整复盘](https://github.com/zhishengyk/liuyao/blob/main/docs/核心规则第三轮复盘.md)；对应[评估证据归档](https://github.com/zhishengyk/liuyao/releases/download/v0.7.0-alpha.4/liuyao-evaluation-2026-09-12.zip)保持原封存版本。

下载后的排盘、检索和原文回查在本地运行。默认uv启动器可能联网核验包缓存；完全离线启动需要先准备缓存，再显式使用 `--offline`。
