# 0.7.0-alpha.3 手切语料与检索修正预发布

完成六本书的人工切片及反馈资格审核，加入理法、象法及两部《增删》的剩余批次，补充原图盘面抽查和同例重刊关系。文本覆盖表示原文已被切片或明确列为排除项；不等于每个盘面均已独立核对。规则、案例、有效反馈和盘面通过数以发行包 `release-manifest.json` 为准。原问无法被反馈核验的案例归档为噪音，明确的作者预测失败仍作为反例保存。

- 增加显式案例全文查证：`kind=case, case_text_scope=full` 可按作者断语及反馈查原书；普通相似例仍按原问和盘面检索，噪音和待审核案例不入检索。
- 修正两条天气例的结果角色，以及多次起卦中原问与反馈错配的问题。各盘分别保留求测人和当时已知背景，后续追问不混入初始输入；有原文依据的后盘已知信息须注明披露阶段。原书明确共用的日期附精确来源，不能据此借用其他卦的六爻值。
- 独立15问审查发现自动事项加分会把劳动仲裁排在涨薪案例之后，因此移除该加分和无效候选通道。裸关键词仍可能把求职与住房、奖金混排；显式事项筛选测试通过不能证明该缺口已解决。助手指南要求核对主体、资金方向与原问，发现错题后重查并回读出处。
- 向量建库只编码可检索记录，保留原文归档并复用未变文本缓存；常规检索不默认启用慢速神经重排。
- 源码继续只保留代码、小型清单和文档；语料与人工审计放在独立、带SHA-256的Release压缩包。支持按清单恢复和从已完成分片重新打包，草稿和未合并的审核批次不发布。
- 完整测试套件与隔离安装检查成为预发布的必要门槛。上述无筛选求职排序问题保留为显式 `xfail`，不记作已经通过或已经修复。

第二轮Astra旧库复盘发现，已排除案例的事后评论仍被当独立规则返回，破坏了一个日期命中的独立性；另一可核验例弃断了原问所要的具体时点。此轮不报告总体准确率，详见[第二轮复盘](https://github.com/zhishengyk/liuyao/blob/v0.7.0-alpha.3/docs/核心规则第二轮复盘.md)。后续测试须同时检查案例、事后评论及各书重刊的隔离范围。

这是预发布数据更新。原始 Word 缺失造成的残缺、未独立核对的盘面及尚未确认的跨书重复仍保留相应状态，不据此保证预测准确率。
