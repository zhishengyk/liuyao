# 核心规则 pilot 独立评分

本评分在确认预测锁定并获准揭晓后完成，未读主任务评分，未联系解释者改答案，未修改冻结预测或规则。预测 JSON 的 SHA-256 为 `925e28b7f0efcd27fbd68658a3a116e86f5773fc8e9d652d9b760904bd1372e7`；锁文件为 `6799dcb7c58e6dd2ed932b977a7f5fb5ffc6295973ce6b21513444a6bf65e782`。三个预测文件、输入、封存 key 及引用文本哈希均复核通过。逐维原文证据与完整结论见同目录 `independent-grading.json`。

**不能把这轮报告为“6 例全对”。** C03、C04 的宽方向有反馈支持，C01 只部分符合先推进、后不稳定的序列。C02 没有法院胜负判决；C05 没有原店经营损益；C06 没有实际成绩变化。这些维度不能强行二分正确与错误，也不能用原作者的未验证断语补齐。未预注册数值权重，因此不在揭晓后另造总分或通过率。

| 案例 | 冻结预测与明确反馈比较 | 核心规则应用 |
|---|---|---|
| C01 男友发展 | 预测短期可推进、长期不稳，与后来成婚、离婚宽方向部分相符；“谈婚、订婚或成婚有机会”不等于明确预测结婚。怀孕、洗澡滑倒、流产与失去生育能力均未预测。 | 父卯与寅日同木、现有交往及未婚条件处理正确；婚事和婚后稳定分开，并保留六冲变六合等反证。 |
| C02 官司 | 反馈为因钱起诉，后来嫌麻烦撤诉。预测难赢仅在宽泛未得所求上相容，没有预测撤诉或金钱争议；**撤诉不能算法院败诉命中**。 | 世应取用及世午动逢未日合绊基本正确；没有把四爻明动日冲误作暗动。未把合绊落实到停止诉讼的具体事件。 |
| C03 卖房 | 近期难成交与“卖了很久仍未卖出”受阻方向一致；未给售出时间。议价困难、报价未达预期没有反馈确认，不能计为细节命中。 | 主财、父为房，父亥化财丑回头克及交易分支均有依据；未错套婚史或将三合候选直接当成交应期。 |
| C04 侄子昏迷 | 苏醒恢复方向与“开始恢复知觉，可以认人”相符；**没有预测 10 月 12 日／书内戌月应期**，也未具体预测认人。不能扩成完全康复或长期预后命中。 | 子孙申为侄子、戌为元神，巳动生戌、戌日冲暗动生申的救应链复现。白虎父午静与朱雀父巳动分清，使用其他六神父母动克世的一般分支成立。 |
| C05 租店 | 条件性偏吉与卦主对原店“不太好”的评价方向不符；另租、开业、食品档口均未预测。**原店未租，没有经营损益，盈利预测本身不可实证评分**。 | 将指定店铺好坏缩窄为经营收益，主财辅父有通则但题意覆盖不足；未落实应位财源月破日克和日合静爻取替代店铺的路径。静爻平合完整细则也不在这次两条理法规则内。 |
| C06 学校 | 反馈只确认学校不错、试听一课后最终没去。对学习有帮助仅与正面学校评价弱相容；**未入学，不能验证成绩提高**。未预测试听后不正式就读。 | 应父为学校的太极点合理；但一面以午日合绊减弱忌神，一面用午动生丑支撑暗动通关，尚未证成合绊下生助仍有效。 |

C01 的取用和反证处理较完整：女问现有男友取应位官鬼亥，父卯仅辅助婚事；正确核对亥水生寅木，没有把工具相对方向标签误读为寅日生亥。所引古文对六冲变六合甚至主张不看用神径断吉，预测没有隐去这条强反证，但最后选择长期不利仍是书际权衡，不能称各书一致支持。本例原作者初断不能结婚、无生育能力，与最初成婚怀孕反馈冲突；后来的离婚和生育能力丧失不能倒算首断全对。

C04 的暗动条件成立得较完整：戌月不得生扶，却有明动巳火生助，辰日冲静戌，再生旺而有根的申金。原作者借第四爻父午白虎构造典型虎父伤身，解释者没有复现借神步骤；它使用已提供规则的其他六神分支，不能因为没有强行借神就判错。车祸昏迷本来已在输入中，不能计作预测发现。未报苏醒应期属于有反馈维度的覆盖缺失，不能说成报错日期。

C05 的收益论证不能仅因与作者结论不同就全判错误：财酉得月生、初爻子丑临月发动，旺动空及化空仍有气，均有通则支持；世受月土及动丑克也作为反证列出。问题在于指定店铺选择被经营假设取代，应未月破日克和替代店铺方向未处理充分。原作者由应未衰推“挣不到钱”，也未获得原店实际经营反馈，不能拿来当利润 gold。

C06 有两处必须分开处理。其一，解释者的暗动救应链仍有条件缺口：所引日合动爻规则说合绊，而午火是否仍足以生丑没有解除合绊或另一明确条件作支撑。“较弱暗动”“力度不确定”是保留意见，不能代替证明。新评允许弱暗动是有效反证，因此这里记为规则取舍未解决，不判丑绝不可能暗动，也不以作者最终未去反推暗动论必错。其二，**源文自身称“应爻父母酉金……生世爻”，但世爻是妻财午火，酉金不能生午火**，同段又写世发动克应。这句生克方向冲突不能设为必须复现的 gold。学校条件不错与求测人最终不去可以同时为真，也都不等于成绩已提高。

没有六神论证的案例，不因缺少六神而扣分；原作者的法院维护对方、旧房、房价过高、起卦前已选中另一店铺、学校心理态度等，均按各自反馈是否明确确认处理。所有六例都没有给具体时间预测，其中 C04 原反馈确有日期，其他多数例没有足以验证具体应期的反馈。

本轮只验证预选核心规则的应用及书中反馈复现，尚非六书全库或相似案例检索效果验证；书中记载也没有在现实中获得独立核验。
