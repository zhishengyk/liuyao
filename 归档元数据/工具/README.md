# 转换与续跑工具

这些工具用于本次本地资料库转换。原文件位于仓库中的 `003周易命理资料`，依赖、识别缓存和断点记录位于仓库根目录的 `.word-conversion-cache`。

需要继续尚未完成的 OCR 或重新汇总时，在仓库根目录运行 `继续转换.ps1`。如果 OCR 已在运行，脚本会退出，避免重复启动。

脚本使用本机已有的 Word、PowerPoint、Pandoc、7-Zip、Java 及本次安装在缓存中的 OCR 依赖。只移动本归档文件夹后仍可阅读 Markdown，但要再次执行转换，还需要保留原资料与运行环境。

扫描识别原始记录在缓存中；`_校验` 保存完整性检查及需重点核对的 OCR 页码。本工具不会进行人工逐字校订。
