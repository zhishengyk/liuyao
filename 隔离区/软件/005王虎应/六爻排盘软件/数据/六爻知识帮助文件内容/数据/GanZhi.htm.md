yes">                            </span>**<span style="mso-spacerun:

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>\<\<五行大义\>\>中说, 干支是大挠创制的. 大挠"采五行之情, 占斗机所建, 始作甲乙以名日, 谓之干, 作子丑以名月, 谓之枝. 有事于天则用日, 有事于地则用月. 阴阳之别, 故有枝干名也."</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

十天干<span lang="EN-US">: 甲, 乙, 丙, 丁, 戊, 己, 庚, 辛, 壬, 癸.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

十二地支<span lang="EN-US">: 子, 丑, 寅, 卯, 辰, 巳, 午, 未, 申, 酉, 戌, 亥.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

天干的含义<span lang="EN-US">: \<\<群书考异\>\>中说:</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

甲是拆的意思<span lang="EN-US">, 指万物剖符而出.</span>

乙是轧的意思<span lang="EN-US">, 指万物出生, 抽轧而出.</span>

丙是炳的意思<span lang="EN-US">, 指万物炳然著见.</span>

丁是强的意思<span lang="EN-US">, 指万物丁壮.</span>

戊是茂的意思<span lang="EN-US">, 指万物茂盛.</span>

己是纪的意思<span lang="EN-US">, 指万物有形可纪识.</span>

庚是更的意思<span lang="EN-US">, 指万物收敛有实.</span>

辛是新的意思<span lang="EN-US">, 指万物初新皆收成.</span>

壬是任的意思<span lang="EN-US">, 指阳气任养万物之下.</span>

癸是揆的意思<span lang="EN-US">, 指万物可揆度.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>由此可见, 十天干与太阳出没有关, 而太阳的循环往复周期, 对万物产生着直接的影响.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

十二地支的含义<span lang="EN-US">:</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

子是兹的意思<span lang="EN-US">, 指万物兹萌于既动之阳气下.</span>

丑是纽<span lang="EN-US">, 系的意思, 既萌而系长.</span>

寅是移<span lang="EN-US">, 引的意思, 指万物至此已毕尽而起.</span>

卯是冒的意思<span lang="EN-US">, 指万物冒地而出.</span>

辰是震的意思<span lang="EN-US">, 物经震动而长.</span>

巳是起<span lang="EN-US">, 巳的意思, 指万物至此已毕尽而起.</span>

午是仵的意思<span lang="EN-US">, 指万物盛大枝柯密布.</span>

未是昧的意思<span lang="EN-US">, 指阴气已长. 万物稍衰, 体暖昧.</span>

申是身的意思<span lang="EN-US">, 指万物的身体都已成就.</span>

酉是老的意思<span lang="EN-US">, 指万物老极而成熟.</span>

戌是灭的意思<span lang="EN-US">, 指万物老极而成熟.</span>

亥是核的意思<span lang="EN-US">, 指万物收藏皆坚核.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

天干喻人含义<span lang="EN-US">:</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>甲木属阳, 一般指森林大树, 性质强壮. 甲木有恻隐之心, 具上进心, 好华美的事物而有风雅的性格, 进退有情有义, 处事负责, 但缺乏应变能力, 又因常烦恼故做事多老苦.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>乙木属阴, 指小树花草之类, 性质柔软. 乙木富同情心, 性情和蔼, 外表谦虚, 但内心占有欲强, 虽有才能, 但常烦心.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>丙或属阳, 指太阳, 炎炎炳照之意. 丙火为火之兄, 含有朝气蓬勃, 热情开朗之意. 还含有适合各种社交活动, 但也易被误解为好大喜功.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>丁火属阴, 指灯火, 炉火等, 火势不稳定, 得时有力, 失时无力. 丁火为火之妹, 具有外静内进, 思想缜密的性格. 但是多疑与心机是其缺点.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>戊土属阳, 指大地的土, 广厚茂盛, 又指堤坝之土, 可有力地防止河川泛滥.戊土诚实, 厚重, 性情笃实沉稳, 为人憨直.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>己土属阴, 指田园之土, 不如戊土广厚但易栽植. 己土重视内涵, 多才多艺,行事依循规矩, 但度量欠广, 易生疑心.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>庚金属阳, 指铁, 刀剑, 矿石等, 性质坚硬. 庚金精神粗旷豪爽, 意气轻燥,性情刚烈而重义气, 个性好胜, 具有破坏性, 人缘佳, 容易相处.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>辛金属阴, 指珠玉, 宝石, 砂金. 辛金性较阴沉, 温润秀气, 重感情, 虚荣心强而爱好面子, 有强烈的自尊心. 但缺乏坚强的意志.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>壬水属阳, 指大海之水. 壬水为水之兄, 含有清浊并容, 宽宏大度之意, 能潜伏和包容, 富于勇气. 但也有依赖性强, 凡事漫不经心之意.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>癸水属阴, 指雨露之水, 也有闭藏和内在萌生之意. 癸水为水之妹, 其人平静, 柔和, 内向, 勤勉力行, 然而每爱好猜臆, 注重原则, 不务实际, 故内心常蓄不平, 并时有破坏性, 并且有重情调, 喜钻牛角尖的倾向.</span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>"胎"如人受父母之气结聚成胎, 是指天地气交之际, 后继之气来临, 并且受胎.</span>

<span lang="EN-US" style="font-family:&quot;Courier New&quot;;mso-ascii-font-family:宋体"> </span>

<span lang="EN-US"><span style="mso-spacerun: yes">    </span>"养"像人养胎于母腹之中, 之后又出生, 是指万物在地中成形, 继而又萌发，又得经历一个生生灭灭永不停止的天道循环过程.</span>
