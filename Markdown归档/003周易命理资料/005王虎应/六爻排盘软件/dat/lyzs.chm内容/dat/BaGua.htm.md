**<span style="font-size:14.0pt;mso-bidi-font-size:
9.0pt;font-family:宋体;color:blue">八卦<span lang="EN-US"></span></span>**

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">八卦分别是：乾、兑、离、震、巽、坎、艮、坤 ，<span lang="EN-US"></span></span>

<span lang="EN-US" style="mso-bidi-font-size:9.0pt;font-family:宋体;color:black"> </span>

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">其中乾、坎、震、艮为阳，坤、巽、离、兑为阴，<span lang="EN-US"></span></span>

<span lang="EN-US" style="mso-bidi-font-size:9.0pt;font-family:宋体;color:black"> </span>

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">八卦的顺序是乾一、兑二、离三、震四、巽五、坎六、艮七、坤 八。<span lang="EN-US"></span></span>

<span lang="EN-US" style="mso-bidi-font-size:9.0pt;font-family:宋体;color:black"> </span>

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">八卦的方位分先天和后天，先天方位是：乾南兑东南离东震东北巽西南坎西艮西北坤北。<span lang="EN-US"></span></span>

<span lang="EN-US" style="mso-bidi-font-size:9.0pt;font-family:宋体;color:black"> </span>

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">后天方位是：离南巽东东南震东艮东北坎北乾西北兑西坤西南。<span lang="EN-US"></span></span>

<span lang="EN-US" style="mso-bidi-font-size:9.0pt;font-family:宋体;color:black"> </span>

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">八卦的象是：乾三连，坤六断，震仰盂，艮覆碗。兑上缺，巽下断，离中虚，坎中满。<span lang="EN-US"></span></span>

<span lang="EN-US" style="mso-bidi-font-size:9.0pt;font-family:
宋体;color:black"> </span>

<span style="mso-bidi-font-size:9.0pt;font-family:宋体;
color:black">八卦所属五行是：乾兑为金，艮坤为土，坎为水，离为火，震巽为木。</span>
