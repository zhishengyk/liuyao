此章占住宅之荣枯,定六神之生旺,衰于第几代,旺于第几代,五星妙理,岁,刑,冲,灾害,存亡.纵首章所载,初爻为住宅,二爻为华堂境界.青龙白虎看六神之爻,但有爻空,若子空连丑土也空矣.万五一失.此管公真诀:<span class="mark">但见六爻值子孙空,其家绝于后嗣</span>.<span class="mark">财值六爻,必伤妻妾.兄弟值六爻,必主分食.父母值六爻,艰难子息.</span>只此数条至明后学者!\
\
      \[所占家宅,先看世爻,世决三代之枯荣,应断一生之得失.\]   \
\
      占者卜地,惟程意有感,酗酒嗜欲之辈,莫与其占.世者八卦所值之世,从下数上,看生旺休囚,断过去未来现在,三代兴废存亡,具从世上三代而占.空者,一生无定也.官鬼值世,当家后嗣.子孙值世,维绪永昌.财爻值世,阴损无碍.公亩值世,重修栋宇.兄弟值世,必主分张.火星值世,动则回禄.水星值世,不动安详,衰者不能易发.木星值世,荣达富贵.土星值世,则缺陷,动则重创,难保子孙.金星值世,必主损缺,动则鼎新.二爻无金,飞伏不用,卦爻不用,但以一卦占断,以五星六神讲谈,妙出如神矣.\
\
      **青龙值世,动则喜事.朱雀值世,不动亦占口舌.\
      白虎值世,动则死亡.玄武值世,动则偷害.\
      勾陈值世,动为退失.腾蛇值世,动为怪类.非符矣.**

\[遇凶煞合一为祥,若贫寒儿得一财则发\]\
\
      凶煞者,勾陈白虎之神也.冲合不宜,冲则为祸,合则为灾.吉者,子孙官鬼也.世之贫寒衰矣,谁能救乎?惟财可救.卦中如春占一木,财来合,自然发福不难,最怕刑冲克害,财以合身,合命不空,济在目前,发之不浅.\
\
      \[青龙是福,白虎是禄,福禄不刑,乃为吉地\]\
\
      龙虎者,乃六神之龙虎也.子午相冲,卯酉相冲,谓之冲也.寅刑巳,巳刑申,为之刑也.六神或六冲或自刑,此鳏寡孤独出矣,不冲不刑吉也.四兽需看年月日时,或生虎生一重有一重,或生龙亦然,财爻为用,观其进退,子孙当察其休咎.\
\
      财者,所用之财也.即妻财也.不宜多见财.财空者,损妻财,财动者败财.一重财,生则为进,动则为退,连见二子,无财则绝,宜观其动静进退.\
\
    子孙者,即福禄也.连见二财,有子不承也.将来之事,囚者无气也.休者过去也.察其三代之子孙,看日辰帮助泄流之理,绝处逢生之义.其察四季,当知三代之子孙哉.
