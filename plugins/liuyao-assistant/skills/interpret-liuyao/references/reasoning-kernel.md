# 王虎应式全局断卦推理内核

本文件是断卦推理的唯一权威流程，以王虎应《六爻预测自修宝典》《六爻分类占验技法》《卦例说真》等著作及本人答疑中反复出现的判断主线整理，不另造一套六爻理论。核心顺序：先把原问落到正确用神；日月定根，动爻看趋势，用神自身发动由本位变爻看变化方向；始终核世爻与用神的关系；大象结构只附和主干；最后取应期。

本内核只管推理流程与判断逻辑。插件的工程执行细节（MCP 检索、语料加载、链路审计、版本检查）见上级 SKILL.md 与 condition-review.md，不在本文件维护。

## 总纲三句话

1. **卦答所问。** 先把问题锁死，答案只落在被问的维度上；卦里多出来的信息是旁白，不许抢答。
2. **主干定吉凶。** 一切围绕用神：看日月与卦中各爻对用神的作用。用神取错，满盘皆错。六神、大象、格局口诀都是枝叶，枝叶不许推翻主干。
3. **状态不是删除键。** 空亡、月破、入墓、合绊是"条件"，不是"没有"。每个关键爻分三层记：现在有没有力、象上表达什么、何时兑现。

## 固定流程（八步，不许跳步，不许先有结论再找证据）

这八步是**内部思考顺序和判断纪律**，不是答复模板。给用户作答时按问题的需要自然组织语言、详略自定，不必逐项汇报过程。

### 一、审问

- 把原问拆成维度：事件成败／对象状态／本人得失／原因／应期。各占各的，互不顶替（能找到人 ≠ 人平安；能入职 ≠ 干得长）。
- 记四个属性：一次性事件还是阶段状态；主问还是兼问；初占还是复占；有无时限。
- 兼问降级处理，不套专测该事的最重断法；复占不多数表决——前卦已明，后卦不作独立证据。
- 问题没锁清楚，不进入取用。

### 二、扫盘（只标事实，不下结论）

标出：旬空、月破、日冲（暗动/日破候选）、明动爻及其本位变爻、伏神位置、明显的冲合墓结构。
取用完成后，与主线无关的异常标记停止跟踪——不给每个凶象都安排戏份。

### 三、取用

- 按事项分工取主用神（分工表见附录一）。主用神承载所问结果；其余六亲各管一个辅助维度（单位、工资、分数、文书……）——辅助爻弱不否定主用神，辅助爻旺也不替主用神报成功。
- 不凭持世六亲直接断吉凶。"财持世克文书""子孙持世剥官"是辅助信息，不是结论。
- 用神两现：先取动，再取空破，再看冲合，再看临世应，再看离世应远近；仍难分再看爻位六神。特殊情况允许兼看，但要分清每爻各管什么。
- 用神不现才找伏神。伏神作了主用，单审它的日月、空破和飞伏生克；显爻已有主线时，伏神只作补充信息。
- 角色由"爻位＋原问＋盘面"共同确定，不凭象义硬指派。动爻是应爻，就先读"对方"，再读六亲——兄弟动于应位，第一反应是对方有动作，不是冒出来一个竞争者。
- 取用确有分歧时，候选并列分别推演；不许为了想要的结论反选用神。

### 四、日月定根

- 月建、日辰对用神的生克冲合分别记录，不折算成分数。
- 太岁、时辰默认不进旺衰（年运卦等例外再说）。
- 暗动要审定：静爻有气（临月、得生扶、得动爻生、与月合）遇日冲才算暗动；休囚遇冲是日破。动爻冲静爻也可能引动。

### 五、动爻看趋势

- 动爻是事机，读全链条：谁动（现实角色）→ 化出什么 → 作用于谁。只读前半截必错。
- 一个动爻可同时有多条作用线，先全列，后筛主线，不压成唯一去向。
- 变爻只反馈本位动爻（回头生克、进退、自合），不跨位作用；别的爻也不拿变爻当普通爻生克。
- "动化某六亲"是事件象，过了相关性和力量审查才能当事实用，不许把变爻直接当最终结果。
- 用神自身发动，看本位变爻定变化方向；元神忌神发动，看本位变爻定其力增减。
- 动必有因：动爻按本义落点断不通时（衰极化绝、与本题不接），它的信息不落空，改落在象、应期或旁支上——不判"动了白动"，换落点找。
- 独发是特殊结构，先判功能：报应期／说原因性质／以象定吉凶／占此应彼。不许先套五行生克硬判。

### 六、审有效作用（每条作用问两句话）

1. **与本题有关吗？** 主体、对象、事项、时间尺度对不上，这条关系出局。卦里存在父克子、财克父，不等于它参与本题。
2. **现在真有力吗？** 查制约条件：合绊、空破、入墓、贪合忘生忘克、回头生克、化进退（细则见附录二）。

配套三条纪律：

- **分三层看**：现在有没有力／象上表达什么／何时兑现，互不顶替。空破≠无力——旬空发动仍有力，月破旺动或得生扶也有力；只有衰、破、无气、安静、受克叠加才是真无力。受阻≠删除，将来得时恢复的算"暂时受阻"，不算"没有"。
- **生克分方向**：他生我与我生他、应生世与世生应不是一回事，好处流向谁必须说清。
- **链条逐节验**：连续相生、贪合忘生这类链，每个中间爻有力、每一节当前走得通、终点受得起，链才成立；中间被合住链就断了，冲开才恢复。

### 七、综合定吉凶：四层查完，落到用神

- 结论只有一种推法：月、日、动爻、本位变爻四层都查完，看最终落到用神身上的是什么——得生扶、受克有救，则成；受克无制、无根生扶不起，则不成。不是把吉利和不吉的因素摆两边掂量，而是追一条链：克用神的有没有被解掉，生用神的能不能生效。
- 忌神发动，先看有没有被制服（被日月除根、被合绊、化退化破）：有制服，克就落不实，冲克忌神之时反而事吉；无制服而力大，才是真凶。斩草除根——动爻的根在日月。
- 元神发动，先看用神受不受得起：日月皆克、用神无根，多爻杂动也生扶不起；只有元神独发是例外，神兆机于动。
- 元神是用神之根，不是备用层：用神再旺，元神空伏死绝、飞神克伏、根已断，事亦不成——财无源不发，官无根难升。
- 四层一层都不能漏。断错最常见的原因不是判断错了某一层，而是只看了一层就下结论。
- "定不了"只有两种：主用神取不定；作用确实互相抵消、无法裁决。不许拿"还有细节没查清"当定不了——细节只降把握，不改方向。对象和时限明确的是非问，主线有方向就必须给明确答复。
- 世爻必查（心态、立场、承接力），但普通世旺世弱不单独投票；世本身是用神、世动、世空破，或事项规则明看世应时，才提高权重。
- 世应先分题型：对抗型（竞争、诉讼、比赛）常喜对方弱；协作型（求人、合作、婚姻）才喜应旺生世。
- 六合六冲、游魂归魂、伏吟反吟、三刑、三合、卦名卦宫这类整体信息，只用来修饰过程与性质，附和用神，不单独定成败（细则见附录三）。
- 定程度：有根、受克有救，优先解释为受损、延迟、反复，不直接拉满到最坏结局；无根、克多生少、救援失效才断重。
- 久远问题看元神能否持续生扶，不用当前旺衰线性外推。

### 八、最后取应期

- 应期线索必须来自主线，也就是决定吉凶的那些爻和条件；旁支的空破不许拿来报日期。
- 找"当前最卡用神的条件"，问它何时解除或兑现：空待出空冲实，破待实破、合破、出月，合绊待冲开，墓待冲，化进退化待填实，伏神待冲伏、冲飞或逢值。
- 近事优先日时，远事优先月年；多个条件指向同一时间，把握才大；没有明确触发条件就不强报具体日期。

## 十条禁令（错题本）

1. 不凭持世六亲断吉凶。
2. 不凭象义硬指派角色——爻位先于六亲扩展义。
3. 不把月破、旬空当否决键。
4. 不用"六冲必散、六合必成"一句话定成败。
5. 不数吉凶象条数投票，也不把有利和不利因素摆两边对比——看四层作用落到用神身上的结果。
6. 不用应期层信息（破、空、出月）推翻吉凶方向。
7. 变爻不跨位生克；旁爻不生克变爻。
8. 用神不现才找伏神，伏神不与显爻平权。
9. 大象、六神、口诀附和主干，不替代主干下结论。
10. 复占不多数表决，兼问不套专测重法。

## 复盘纪律

对照反馈断错时，按"取用 → 定根 → 动爻 → 制约条件 → 落点"逐层找错因，只改出错的那一层，不全盘推翻重换一套理论。

# 附录

## 附录一：取用细则

断卦第一关。取用错了，后面全盘皆错；取用对了，旺衰生克自会给出答案。


### 取用总原则

- **问什么，取什么。** 先找问事的核心环节，再定六亲。同是读书，问考学看官（争名次），问上学看父母（文书学籍）；同是手机，丢了看财，坏了看父母。
- **主用神只有一个**，承载所问结果。其余六亲各管一个辅助维度（单位、工资、分数、文书……）：辅助爻弱不否定主用神，辅助爻旺也不替主用神报成功。
- 关系身份与事件承载不混。朋友借钱，朋友由应爻承载，钱能否回来仍看财——不能因为朋友的六亲是兄弟，就把兄弟改成钱的用神。

### 事项分工表

以王虎应明示口径为准：

| 事项 | 主用神 | 辅助维度与说明 |
|---|---|---|
| 找工作、面试能否成功 | 官鬼 | "找工作的面试主要看官，当然也不能忽视世应"。父母=单位/文书，妻财=工资 |
| 考学、求职考试、职称评定 | 官鬼＋父母 | 官鬼=名次，父母=成绩与录取通知书 |
| 读书上学（不争名次） | 父母 | 考学才看官 |
| 出国留学 | 父母 | 签证为首要矛盾；官鬼=大使馆 |
| 文书申请类（申请学校、资质） | 父母 | 父母为文书 |
| 在职问升迁、工作变动 | 官鬼 | 父母=单位，妻财=待遇 |
| 跳槽能否成 | 官鬼为主，兼看世爻 | 应爻=要去之处；六冲反吉，六合牵绊；世空=心猿意马 |
| 辞职可否 | 妻财 | 财为养命之源，财旺可辞 |

| 诉讼、竞争、比赛 | 看世应强弱 | 对抗型事项喜我旺彼弱 |
| 代人占 | 用神与亲占同 | 吉凶看所代之人的六亲；世爻只代表事物主体 |

工作类补充定位：五爻=单位主管领导，月建=最高领导，日辰=顶头上司；官鬼旺相工作易找，休囚难寻；官鬼生合世为吉，生应爻为"无情"（好处流向他人）。

### 用神多现的取舍

同六亲两现，按序取"有特殊意义"的那个：

1. 一动一静，取发动者；
2. 同动同静，取旬空、月破等异常者；
3. 再看逢冲、逢合；
4. 再看是否临世、临应；
5. 再看离世应远近；
6. 地支仍同，用爻位、六神、现实角色消歧。

这不是死排序：一空一破、一动一空等结构允许兼看，但要分清各爻分别承担结果、应期还是细节，不双倍计票。用神发动优先审动爻；空破之爻恰好承载事件时，不得因空破舍弃。

### 用神不现与伏神

- 本卦有相应六亲，先从显爻取用；**用神不现，才到本宫找伏神**。
- 伏神作主用后，单审：日月旺衰、空破、有无元神、飞神对伏神的生克。
- 飞来生伏、伏克飞为有利条件；伏生飞为泄；飞克伏为不利——仍要与日月、动爻合看。
- 飞神空亡、月破或被日月制服，伏神易出（"空下伏神，易于引拔"）；飞神旺相压住，伏神纵旺也待冲飞、冲伏才出。
- 显爻已有主线时，伏神只作人物、原因、潜在信息的补充，不许替换显爻主线。

### 角色对应的纪律

- 爻位先于六亲扩展义：动在应爻先读"对方"，持世先读"本人"，再读六亲。
- 六神、爻位、象义帮助回答"这爻现实中是谁"，但必须与原问、取用体系、盘面三者共同成立，不凭单一象义硬指定身份。
- 领域常规六亲在卦中明显承担了别的现实含义时，允许角色改写（如已升官者问"领导找我谈话是否撤职"，官鬼可表忧虑而非职位）——改写须有原问与盘面依据，不为迎合答案任意重命名。

### 生克的方向与好处流向

生克要看方向：他生我与我生他、应生世与世生应、财生世与世生财，都不是同一个结构。

- 求财、升迁等事项：用神发动反去生应而不归世，为"无情"，好处流向他人；应又发动生回世，则重新形成有情。
- 测自己的事，主用神静临应爻、与世爻没有生合关联，先问这好处是不是落在他人身上（测己官运而官临应＝他人之官、领导变动），不直接计入本人吉凶。
- 疾病、出行等事项不套"用神生应=凶"。
- 三合、六合、连续相生先问与本题是否相关：成局不等于相关，相关还要再判对用神是生、是克、是助旺还是只表"多人、共同"之象。

## 附录二：爻的状态细则

空、破、墓、合、进退、回头生克——这些决定"这条作用当前能不能发生"，不是统一加减分项，更不是删除键。


### 分三层看

每个关键爻、每条作用都分三层看，互不顶替：

1. **现在有没有力**：此刻有没有实际生克能力；
2. **象上表达什么**：空、破、墓、合在现实层面表达什么状态（未落实、破裂、收藏、牵绊……）；
3. **何时兑现**：什么条件（出空、实破、冲开、逢值）使它生效或失效。

只有衰、破、无气、安静、受克叠加，才判当前无力；只是将来得时增强的，算"暂时受阻"，不算"没有"。

### 旬空

- 旬空发动即可起作用；旺相空爻、得日月或动爻生扶的空爻也有力。
- 空则暂避生克（避空）：吉神空暂不受生，忌神空暂不能克；出空、冲实后照常兑现——克用神的爻空，出空之日应凶，不问吉凶时别提早前下"不受克"的结论。
- 出空、冲实是兑现条件，不是吉凶反转条件。
- 旬空之爻逢日合，合不能填实空亡。
- 世爻空亡常表心不实、观望，不直接等于事败。

### 月破

- 月破爻旺相发动或得生扶，也可有力；月破不等于无效。
- **月破与回头生/回头克并存时：回头生克定吉凶方向，月破管应期和当下状态。** 问吉凶不问应期时，不许拿月破否决回头生克的结论。
- 修复与兑现：实破（逢值）、合破（逢合）、出月。
- 月建冲的是变爻时，不是把坏变爻"冲走"，而可能使本位动爻成"化破"——变爻只在本位内处理。

### 入墓

- 用于吉凶的墓主要是日墓、动墓、化墓；**月墓通常只取象**，不作主吉凶的力量条件。
- 入墓是减力、受限、收藏状态，不等于失去生克权。
- 用神旺相入墓多可无妨；休囚空破再入墓才明显加重。
- 冲墓、冲出可解；但用神自身发动、本位变爻来冲，不按"冲出"论，属自身变化（反吟类），看不稳定加剧。

### 合

分来源，含义不同：

- **月合卦爻**：通常论合旺，不是默认合绊；仍要看月是生合、克合还是普通合。
- **日合卦爻**（不分动静）：默认合绊、受牵制；"静爻日合当动看"的旧说不作生产规则。
- **被有效动爻合**：形成合绊候选，原有生克暂停，冲开后恢复。
- **本位动爻与变爻合**：自合、绊住、迟滞，只在本位处理，不跨位。

冲开合局先问"谁恢复作用"：元神被合，冲开恢复生用；忌神被合，冲开恢复克用——"冲开"本身不是固定吉象。
事项优先：近病不宜用神逢合，久病反可因合留命；出行动而逢合被绊；行人逢合待冲回。

### 冲

先分来源，再分功能：

- 来源：主卦六冲／变卦六冲／月建冲（入月破体系）／日辰冲（分暗动、日破、冲实、冲起）／动爻冲静爻／本位变爻冲（属反吟，不和外部冲混用）。
- 功能：冲散、冲开、冲动、冲破、冲出——同一地支相冲，来源和事项不同结果相反。
- 事项语义：近病喜冲、久病忌冲；诉讼、生育等有专门六冲含义。不许用"六冲必散"跨事项定成败。

### 暗动与日破

- 静爻有气（临月、得月生扶帮比、得动爻生、与月合、长生于月）遇日冲 → 暗动；
- 静爻休囚被月克伤再遇日冲 → 日破；
- 旬空被日冲，兼审冲实/冲起与本身有气无气；
- 动爻冲静爻（尤其独发冲用神）也可使静爻暗动。
- 静爻之间不随便生克；旺相静爻可生克休囚静爻，力量次于动爻，多主现状而非变化。

### 化进化退

带时间条件的状态转移，不打固定分：

- 旺相动爻化进：乘势而进；
- 休囚动爻化进：先记趋势，待得时才真正推进；
- 动爻或变爻一方空破：待填实、实破后进；
- 化退而动变皆旺：近事可旺而不退，远事渐退；
- 休囚化退：退势较快；一方仍旺：常待其转休囚时退。
- 事项语义门：失物、行人、已分手者、离去的朋友——"退"可表回返，"进"反表越走越远。不脱离原问直接标吉凶。

### 贪合忘生与断链

- 爻因更直接的生、合关系暂不执行原来的克、冲、刑——这条作用只是暂时停住，记住什么条件下恢复，不是永久删除。
- 连续相生先只当候选链，逐节验证：中间爻有力吗？这一节当前走得通吗（被合住链就断了）？终点用神有根受得起生吗？全通才算成事依据。
- 承担通关的爻休囚空破、或用神太弱生扶不起时，不能只凭"贪生忘克"判吉。
- 例外：元神一爻独发，即使用神日月皆克无根，也可能"神兆机于动"而生得起——独发例外优先于一般无根规则。

### 回头生克与化破化绝

- 变爻只对本位动爻形成回头生、回头克、冲合，不跨位。
- 用神化回头克，兼看变爻自身状态：变爻被日辰冲可审"冲去"，被月建克可削弱。
- 用神月破时，本位变爻来合可成"合破"修复候选。

### 独发

一爻独发是高信息量结构，先判功能再谈吉凶：

1. 报应期；
2. 说事情的原因和性质；
3. 淡化普通五行生克，以象为主参与吉凶；
4. 占此应彼，反映未问但更重要的事（须现实上下文能解释"为何神报此事"，并与主答分开标注，不作断错后的补救借口）。

### 过旺与过弱

- 过旺：日月共同生扶拱比＋卦内继续增力才成立；此时再生扶反不利，适度克泄、墓藏可成救应（利害方向反转）。
- 极弱：只用于主用神，要求日月共同明显压制并结合忌神加压。
- 普通无根、月破、空亡、休囚不得直接升级成极弱反断。
- 元神、忌神可论过旺；不另建"过弱反断"。

### 长生十二宫的位置

长生、沐浴……胎养主要用来"辨意"（性质、阶段、部位），主吉凶仍以日月、动静生克为骨架。生与墓可同时成立（金遇丑：丑生金兼金入丑墓），不为墓象删除生克边。死、墓、绝只在独发等明示例外结构中直接提高吉凶权重；墓较轻，死绝更重。

## 附录三：大象结构与应期细则


### 总原则：先附和用神

先看用神与实际生克，再用这些整体信息修饰过程、性质、事项语义。只有该事项有明示例外时，结构才参与定成败；否则不得用"游魂不好""六冲必散""三刑必凶"一句话推翻用神、日月、动爻、动变构成的主干。

### 六合与六冲

- 不是全局"合吉冲凶"。先记下这个整体结构，再按事项规则解释。
- 主卦六冲／变卦六冲：加强反复、分散、不安定的结构信息，**仍审用神**。
- 六合变六冲（合处逢冲）：先合后散的修饰——注意落点。所问之事已由用神动爻作答时，冲的落点在事情的**后续**（成了之后不稳、干不长），不是推翻所问之事的答案。
- 事项专门语义：近病逢冲愈、久病逢冲危；跳槽六冲反吉、六合牵绊；婚姻、诉讼、生育各有专门口径，按事项查，不跨领域套。

### 游魂、归魂、伏吟、反吟

- 游魂：不稳定、心绪不宁、向外变化；归魂：归返、回头。都只附和用神，不单独主成败。
- 伏吟：停滞、痛苦、进展缓慢；吉凶仍以用神衰旺与有效作用为主；日月冲可解滞。
- 反吟分层：本位动爻与变爻相冲（爻反吟）权重较高，按自身变化的不稳定反复处理；仅主变卦方位形成的卦反吟应验率低，默认低权重"反复"修饰。

### 三刑

用神生克为重，三刑为轻；只凭三刑不断吉凶。

### 三合局

- 先审与用神是否相关；无关可以不看。
- 成员资格：日、月、明动、变爻、暗动可参与成局；普通静爻不直接凑局；两支半局看是否含中间帝旺支，缺中神意义很小。
- 成局≠强局：参与爻休囚、回头克、受制时，局可成而松散；空破缺口常成为实空实破后的应期触发。
- 最后判这个局对用神是生、克、助旺、改性，还是只表多人、合作、渠道之象。不用一个"三合=true"直接判吉凶。

### 隔山化爻

一般只用于辨意（中间人、原因链、过程顺逆、身体部位），不定吉凶；顺隔逆隔不越过用神主线单独判成败。

### 应期取法

放在最后，先吉凶后应期。

**先看相关不相关**：应期线索必须来自已经决定吉凶的用神、元神、忌神或关键条件。与结果无关的空破，即使能套出日期，也不拿来报应期。

**找触发条件**：问"当前最影响用神的条件是什么，它何时解除、兑现或得失势"——

| 主线上的状态 | 应期线索 |
|---|---|
| 用神安静 | 逢值、逢冲（结合吉凶与强弱） |
| 用神发动 | 逢值、逢合 |
| 靠元神发动成事 | 元神逢值逢合，或元神空破被解除之时 |
| 被忌神发动所坏 | 忌神逢值应凶；有救则找忌神被克、被冲去、入墓之时 |
| 忌神旺极（临月建又化进之类） | 旺时暂不发作，应其转衰、入墓、被制之月日 |
| 用神/元忌空 | 出空、冲实（这个空确实卡着结果时） |
| 用神月破 | 实破、合破、出月（这个破确实卡着结果时） |
| 入墓、合绊 | 冲墓、冲用、冲开 |
| 化进、化退 | 逢值、逢合、冲开、填实（按其转移条件） |
| 伏神 | 伏神出现、冲伏、冲飞 |
| 一爻独发/独静 | 其地支可参与应期，仍须与结果相符 |

**时间尺度**：近事优先日时，远事优先月年。未来日月不重新排一张旺衰盘，只是用未来的日月去兑现原卦已有的空破合墓进退等条件。

**收敛与克制**：同一时间同时符合主线的多条规律时，把握更大——但这些规律必须全部来自同一条主线，不把无关空破拼在一起。没有明确触发条件时，不强报具体日期。
