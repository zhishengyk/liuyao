# 全局断卦推理内核

实际断卦先执行本文件，再按 `condition-review.md`、GLOBAL 原文和领域原文做证据核验。这里是推理控制层，不是新的六爻理论，也不替代原书规则。

## 核心原则

先推理，后检索。先确定本盘最关键的结果路径，再只针对关键争议检索原文。不要先堆规则、案例、六神或卦名再尝试综合。

## 固定流程

1. **锁定原问**
   - 明确主体、对象、事件、时间范围和最终要回答的结果变量。
   - 把“当前状态”“最终结果”“原因/过程”“应期”分开。
   - 二元问题先明确真正需要回答的 yes/no 维度。

2. **只核盘面事实**
   - 确认年月日、旬空、世应、六亲、伏神、动爻、本位变爻。
   - 此步不下吉凶结论，不用卦名、六神、三刑等提前定向。

3. **建立角色映射并取用**
   - 为世、应、主用神及必要辅助爻写清现实角色。
   - 先按原问取常规用神；若父母、官鬼、应爻等在本盘异常突出，可按原书“客观取用”保留主辅两层。
   - 不得为了得到某个结论反选用神。

4. **判断主用神当前状态**
   - 先看月、日、空破、墓绝等，得到 `current_state`。
   - 当前旺衰只描述“现在怎样”，不能自动推出“最终成败”。

5. **建立有向作用图**
   - 所有生克都写成：`施力者 -> 受力者 : 生/克`。
   - 日月 -> 爻。
   - 动爻 -> 静爻/其他动爻。
   - 变爻 -> 本位动爻；变爻不得跨位作用其他爻。
   - 飞伏、元神/忌神也按同样方向写清。
   - 优先识别回头生、回头克、进退、化用、暗动、冲实、出伏等会改变状态的结构。

6. **构造结果路径**
   - 至少列一条正向路径、一条反向路径（若盘面确有）。
   - 每条路径写成“当前状态 -> 触发结构 -> 结果影响”。
   - 不按吉凶象数量投票；比较谁更直接、谁能真正改变主结果。
   - 同一结构若只影响过程或应期，不得冒充最终成败依据。

7. **形成暂定主判**
   - 在检索前先写一个内部暂定判断：偏成 / 偏不成 / 未决，以及最关键的 2-4 个结构。
   - 若主线已清晰，不得因为次要未知自动改成未决。
   - 若主用神无法确定或同层关键证据真正冲突，再保留未决。

8. **只检索关键争议**
   - 优先检索：取用依据、关键有向作用是否合法、关键动变如何裁决、是否存在直接例外。
   - 规则优先于相似案例；案例用于机制核对，不用“故事相似”替代结构推理。
   - 检索结果若与暂定路径冲突，回到具体前提逐项修正，不按命中数量投票。
   - 已有足够直接原文后停止检索。

9. **最后补象法与应期**
   - 理法先定方向。
   - 世应、六神、爻位、卦名、刑害等用于解释过程和细节，除非原书明确把它们作为该题的成败条件。
   - 应期必须绑定到能让结果路径发生状态变化的触发点；没有明确触发就不强报具体日期。

## 输出纪律

最终答复优先给：
- 主判；
- 2-4 个决定性结构；
- 最大反证；
- 若能确定，再给应期。

不要把完整内部路径卡、检索日志或所有规则堆给用户，除非用户明确要求审计。
