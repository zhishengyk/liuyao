# 王虎应式全局断卦推理内核

本文件是执行控制层，依据《增删卜易评释》中反复出现的判断主线整理，不另造一套六爻理论。核心顺序是：**先把所问落到正确用神，再判断日月与动变对它产生的真实有效作用；先以五行理法定方向，再取象，最后定应期。**

## 一、总原则

1. **用神是主轴。** 先明确所问维度，再取真正承载该问题的用神；世爻不是所有问题的默认结果爻。
2. **五行生克主吉凶，象法主辨义。** 六神、爻位、六亲扩展象义、长生十二宫、游魂归魂、卦名等通常用于说明人物、性质、原因、过程。它们可以在前期帮助确认现实角色和来意，但不得脱离理法单独定成败；领域原文明示例外时除外。
3. **先问相关，再问有效。** 卦中存在的关系不一定与当前原问有关；先确认这条关系是否属于当前人物、事项和结果维度，再判断它有没有力量。不能因为世应有生合，就默认与所有问题相关。
4. **看有效作用，不看关系数量。** “能生”不等于“生得动”，“能克”不等于“克得成”。元神、忌神、动爻都要先判断自身是否有力、是否被合住、入墓、回头克、化退、空破等限制。
5. **动而有因，受限不等于无信息。** 动爻即使当前休囚、空、破或受制，也不得直接删除；区分“现在不能充分作用”和“未来得时后起作用/通过动变表达事件”。
6. **空破是状态，不是删除标记。** 旬空、月破可能表示暂未落实、受限、人物心理或应期条件；不得看到空破就把该爻从推理中移除。
7. **日月不能简单相加。** 分别记录月建、日辰对关键爻的生克冲合及其作用性质；有动爻时仍要继续看动爻怎样作用用神。
8. **生克有方向，也有利益流向。** 他生我、我生他，财生世、世生财，应生世、世生应，都不是同一个结构；“生”本身不能自动标成吉。
9. **不按“吉象/凶象条数”投票。** 比较哪条作用真正落到用神和原问结果上，哪条只是过程、象义或应期。

## 二、固定执行顺序

### 0. 锁定原问

先回答以下问题，不明确就不得进入主判：

- 谁是求测主体、对象是谁；
- 问的是哪件具体事情；
- 问的是当前状态、最终成败、本人得失/喜忧、原因细节，还是应期；
- 有无明确时限，是目下、阶段性还是久远；
- 问的是“是否发生”，还是“发生到什么程度/是否全部实现”。

复合问题拆成多个结果维度。不得用“当前旺衰”替代“最后能否办成”，也不得用一个未决覆盖多个独立维度。近问和远问必须分别处理：同一结构可以支持“眼下有”而不支持“久远有”，也可能相反。

### 1. 建立现实角色并取用神

按原问把世、应、六亲及必要伏神映射到现实对象，再取主用神。

- 先用事项常规取用作为候选，不得只凭某六亲持世直接断吉凶。
- 用神两现时，不机械选择“最旺、非空、非破”的一爻；结合动静、空破、世应位置及现实对应判断。
- 用神发动时优先审动爻；空破之爻若恰好承载事件，不得因空破舍弃。
- 某些事项允许多个同类爻分别承载不同现实角色时，分别保留，不强行并成一个用神。
- 取用存在真实分歧时，保留候选并分别推演；不得为了得到目标结论反选用神。
- 六神、爻位、六亲扩展象义可以帮助回答“这个爻现实中是谁/是什么角色”，但角色映射必须与原问、用神体系和实际盘面共同成立，不能仅凭象法硬指定身份。

### 2. 建立用神基础状态

只描述“现在是什么状态”，暂不下最终成败。

分别记录：

- 月建：生、克、冲、合、比扶及月破；
- 日辰：生、克、冲、合、暗动/日破等；
- 旬空、伏藏、是否有根；
- 用神自身动静及本位变爻。

日月各司其职，不折算成简单分数。用神月破临日、日月一生一克等结构，要保留双方作用，继续结合动爻判断。

### 3. 区分静卦与动卦

**静卦：**
- 先看日月对用神；
- 再看卦中旺静爻对用神的实际生克；
- 相互参断。

**动卦：**
- 先保留日月基础；
- 再以实际动爻、暗动及本位变爻为主要变化源；
- 不因两个静爻五行相生克，就自动制造主动作用链。

### 4. 求“相关且有效的作用”，不是只列生克

先过两道门：

1. **relevance_gate**：这条关系是否真的参与当前原问维度？主体、对象、事项、时限不对应，就不进入主结果路径。存在世应关系，不代表世应一定与本题有关。
2. **effect_gate**：关系虽然相关，但当前是否真正能发生？再检查旺衰、空破、墓合、回头生克、进退及其他门控。

通过后，再把关键作用统一写成：

`施力者(现实角色,scope,position) -> 受力者(现实角色,scope,position): 生/克/冲/合`

同时记录**作用方向**和**利益流向**。应生世与世生应、用神生世与世生用神必须分别解释，不能只记“相生”。

#### 动变边界

- 日月可以作用本卦关键爻及实际变爻；
- 动爻可按所采用原文规则作用目标爻；
- 变爻只对本位动爻形成回头生、回头克、冲合等反馈，不跨位作用其他爻；
- 其他爻也不得把变爻当普通本卦爻随意生克。

这里必须区分两类“变爻信息”：

- **interaction_semantics**：五行作用权。变爻只反馈本位动爻，不跨位生克。
- **transformation_semantics**：事件转化象。原爻“动化官、化财、化父、化兄”等，可以在有事项原文/案例支持时描述角色、状态或事件的变化；它不是一条跨位生克边，也不能机械理解成“变爻就是最终结果”。

例如“子孙动化官”可在功名语境中形成职位变化的候选事件象；“初爻动化财”可在出行语境中结合初爻脚力取财象。是否采用仍要回到原问、用神和事项规则。

#### 元神、忌神、仇神

不能只因五行关系就认定作用成立：

- 元神先判断是否有力，再判断能否生用神；
- 忌神先判断是否有力，再判断能否克用神；
- 用神本身若无根、衰极，元神有力也未必救得起；
- 正反力量接近时，再看元神、仇神的实际旺衰与作用。

#### 常见“作用门控”

遇到以下结构时，必须判断它是否使原本的生克暂时失效、转向或等待触发：

- 贪合忘生/忘克；
- 回头生、回头克；
- 化进、化退；
- 入墓、出墓；
- 旬空、出空、冲实；
- 月破、实破、合破、出月；
- 暗动；
- 飞伏关系。

这些不是统一加减分项，而是改变“这条边当前能不能发生”的条件。

尤其注意：动爻当前因空破、休囚或受制而无力时，不等于这条信息永远失效。若原文允许其出空、实破、得时后恢复，应记录为 `delayed_active`，而不是 `absent`。

### 5. 形成结果路径

对每个结果维度分别写：

`当前状态 -> 有效作用/受阻结构 -> 未来状态变化 -> 对原问的结果影响`

至少保留：

- 主要成事/有利路径；
- 主要失败/不利路径；
- 最大反证或尚未解决的门控条件。

只保留真正能作用到用神、世爻或该结果承载关系的路径。只影响原因、过程、人物性质的象，不得冒充最终成败路径。

#### 时间尺度与“寻根”

久远问题不能只看用神当前旺衰。除用神外，必须兼看元神/根源是否能持续生扶，以及潜伏的忌神未来是否可能得时恢复作用。当前旺而无根，可以只代表“目下好”；当前弱但有根、有救，也可能只是暂时受挫。

#### 结果轻重

同一方向还要判断程度：

- 用神有根、受克但有救、克之不尽：优先解释为部分受损、延迟、降级、反复，而不是直接升级成最严重结局；
- 用神无根、克多生少、关键救援失效：才加强失败/重损判断；
- 疾病等高风险事项必须结合原问严重程度和事项专门规则，不能由“用神受克”直接跳到极端结果。

### 6. 加入世爻与事项专门规则，完成主判

基础理法形成后、最终落判前：

- 原问涉及“我能否得到、我是否受损、我能否承受”时，再把世爻纳入结果裁决；
- 查对应事项章节的专门规则，处理求财、工作、婚姻、疾病、行人等语境中的特殊取用和状态语义；
- 进退、空破、六合六冲等不得脱离事项语义机械解释，例如归期、找人等事项可能出现与一般“进吉退凶”不同的现实含义。
- 世应要先判断关系模式：竞争/诉讼/比赛等对抗型问题，往往希望对方弱；求人、合作、交易等协作型问题，则可能希望应旺而生世。不能把“应旺”或“世应相生”写成跨事项通用吉象。

综合后形成内部主判：偏成 / 偏不成 / 未决，并列 2–4 个真正决定方向的结构。只有主用神无法取定，或同层关键证据确实无法裁决时，才保留未决。

### 7. 再做定向检索和证据核验

不得在前面先做大范围案例/RAG堆叠。

只检索当前主线真正需要解决的内容：

1. 取用是否有直接依据；
2. 某条关键生克是否有作用权、是否被门控；
3. 该事项是否存在专门规则或例外；
4. 王虎应新评释是否修正原书旧说；
5. 必要时找同机制案例核对，不按故事相似直接套结论。

规则优先于案例。案例分为直接、同结构、机制类比、反向类比、背景；机制类比不能单独决定主判。

若不同作者真实冲突，按 SKILL.md 的作者裁决规则处理。检索无新信息时停止，不为凑证据无限扩搜。

### 8. 理法主判后完成取象

象法不是完全等到最后才“第一次看”。前面的角色映射与原因识别阶段，可以低权重使用六神、爻位和六亲扩展象义做消歧；但主吉凶仍必须由理法完成。主方向确定后，再系统使用：

- 六神；
- 爻位；
- 六亲扩展象义；
- 长生十二宫；
- 游魂归魂；
- 卦名、卦宫及其他象法；

解释人物、原因、性质、地点、过程和表现。

若象法与理法方向冲突，除非有该事项的直接原文把象法列为成败条件，否则不得用象法推翻已成立的有效生克主线。

### 8.5 多动、多问与重占

- **多爻纷动**：先尝试围绕主用神和有效作用找主线，不因“动多”自动判乱。若关键路径确实互相冲突、人物状态反复且无法裁决，可建议再占一卦合参。
- **重占不是刷结果**：再占用于解决真实疑点，不能因为第一卦不合预期就反复摇到满意为止。
- **一卦多断**：王虎应认为高水平时可以，但一事一占信息更集中。用户明确同时问多个事项时，可以逐维分析；普通预测仍以原问主维度为先。
- **占此应彼**：只作为高级例外，不作为预测失败后的补救解释。除非原问本身不合理、用户明确心怀多事，或盘面有非常强且可核原文的旁支结构，否则不得说“其实卦答的是别的事”。即使出现高置信旁支，也必须与主答分开标注，不能替代原问结论。

### 9. 最后取应期

先问：“为什么现在还没发生/为什么现在受阻？”

应期绑定到使结果路径发生状态变化的条件，例如：

- 空 -> 出空/填实/冲实；
- 破 -> 实破/合破/出月；
- 合住 -> 冲开；
- 克神受制；
- 元神恢复作用；
- 进退神逢值/逢合；
- 用神或关键变爻到位。

应期规则必须结合事项语义、吉凶方向和事情远近。近事优先日时，远事优先月年，但仍以原书该事项触发机制为准。没有明确 `transition_rule + trigger_edge` 时，不强报具体日期。

## 三、工程中间表示

DAG、`current_state`、`result_path` 是帮助 AI 忠实执行上述理法的内部表示，不是新的六爻术语。

推荐最小记录：

```text
question_dimension
role_map
yongshen
base_state
relevance_edges
effective_edges
blocked_edges
delayed_active_edges
transformation_semantics
time_horizon
effect_degree
positive_path
negative_path
main_path
domain_exception
timing_trigger
```

不要把完整内部推理日志直接展示给用户，除非用户明确要求审计。

## 四、默认输出

普通断卦优先输出：

1. 主判；
2. 主用神及一句取用依据；
3. 2–4 个决定性有效作用；
4. 最大反证/限制；
5. 原问需要时再给应期与象法细节。

证据不足时明确指出缺的是取用、作用效力、事项特例还是应期，不用“资料很多所以未决”代替具体缺口。
