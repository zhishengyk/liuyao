使用本插件的 `build_chart`、`inspect_chart`、`search_knowledge`、`get_topics`、`get_outline`、`get_source`。实际断卦先完整读取 [生产断卦流程](references/source-prompts/GLOBAL.md)，再只读取当前原问对应的领域 `PROMPT.md`。理论依据使用 `kind=rule` 定向检索并以 `get_source` 回查。

## 新任务首次使用时检查更新

每个新任务第一次触发本 Skill 时调用一次 `check_update(channel="auto")`，从 GitHub Releases 检查当前 MCP 是否有更新；不要在同一任务重复检查。若返回 `update_available=true`，向用户报告 `latest_version`、`release_url`、`wheel_url` 和通用 `uvx_command`，说明需要把当前 MCP 客户端的启动配置改为该 GitHub wheel，并在新任务中重启服务后生效。当前任务继续使用已经加载的同一版本 Skill、Prompt 和数据库，禁止热替换或混用新旧版本。若检查失败、离线或没有新版本，继续正常断卦，不把更新检查当作阻塞。此流程不依赖任何特定 MCP 客户端，也不修改其他插件或配置。

固定流程：

1. 锁定问题。明确对象、关系、动作和时限；缺少问题或问题含糊时先询问。只有用户明确要求射来意时才推测，并标明不是正常问事预测。独立事项原则上分占；同一事件的当前状态、后续结果和应期可以分层说明。
2. 核盘。六爻按初爻到上爻输入：0 老阴、1 少阳、2 少阴、3 老阳。核时间、时区、动爻、本变卦、世应和六亲；程序事实与解释分开，不补造缺失输入。
3. 按事项取用。在最终判向前读取领域入口，先逐条 `get_source` 读取其中“必读基础规则”及 `required_contexts`，再按“固定检索顺序”用 `kind=rule` 查询当前盘面；明确主用神、世应现实角色及必要辅助爻。有分歧时保留候选和条件。
4. 判断作用是否成立。核用神自身、元神能否实际生、忌神能否实际克、动爻、本位变爻、飞伏、空破墓绝。静卦结合日月和旺爻；动卦先还原动变作用链，再以日月判断是否有力。不得使用“任一救应成立就必成”的短路公式。
5. 领域规则和例外参与后再综合结果。只回答原问；无可靠主线时允许“倾向但条件不足”或“不可判断，需补充问题或重新起卦”，不为覆盖率强制 yes/no。
6. 理法定向后再取象。六神、爻位、三刑、十二长生、卦宫和主变卦只补人物、原因、位置、过程和趋势；没有作者明确依据时不得反向推翻理法主线。
7. 最后取应期。先有结果和实际机制，再找未来触发；区分近事和远事，最多一个主应期和一个必要备选。没有可靠触发就写“应期不可定”，不凑日期。

工具边界：

- `build_chart` 默认 `detail=compact`；需要条件检查时调用一次 `inspect_chart`；完整程序审计才用 `detail=full`。
- `build_chart.relation_semantics` 定义关系方向。所有生克写成“施力者 → 受力者：生/克”；“受生/受克”必须反转方向。
- `search_knowledge` 生产接口只按初始问题和事前背景检索案例，并只返回事前资料；不得把期望结果写入查询。预测所需方法优先使用 `kind=rule`。
- 领域 Prompt 的固定 evidence ID 是最低知识，不受 top-k 排名影响；动态查询必须加入当前盘面的具体六亲、爻位、动变、空破墓绝、主体、动作和时限。检查 `query_terms` 与 `unmatched_query_terms`，并主动补查可能推翻当前方向的相反规则。
- 案例接口只提供起卦时已知的材料；需要评测时使用隔离工具。
- 原文必须用实际返回的 evidence ID 回查。`exact_quote` 必须逐字存在于 `get_source` 返回文本；改写应标为概述。
- `patterns` 是机械结构提示，不直接推出吉凶。用神由当前问题和原文依据确定，程序不替用户选用神。
- 关键规则的 `required_contexts` 必须一并阅读；预算省略时补读，不能只摘口诀。
- 检索排名、向量相似度和案例表面相似都不是正确率。规则冲突先核对象、角色、方向、层次、时限和前提，不按数量投票。
- 盘面图片或题面与 `build_chart` 冲突时先回源核对；不能为了继续作答自行选一个版本。

最终回答只包含：

- 结论：可判断、倾向但条件不足，或不可判断；
- 置信度及原因；
- 主用神与关键作用链；
- 主要反证或不确定项；
- 应期（能确定才给）；
- 实际回查的原文依据。
