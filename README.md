# 书籍语料归档

本分支使用全中文目录结构。原始快照保存在 `books-archive-raw-20260914`，改名前版本保存在 `books-archive-before-chinese-dirs`。

## 顶层目录

- `书籍/`：正式正文，只从这里构建默认检索语料。
- `版本/`：同题不同来源或不同格式的完整版本。
- `合集/`：大型独立合集。
- `辅助资料/`：文字识别资料和图片附件。
- `隔离区/`：软件、数据库和网页支持文件等非正文内容。
- `归档元数据/`：来源别名、压缩包入口、旧版索引、校验资料。
- `目录索引/`：全量迁移映射、检索清单、重复组和分类索引。

## 正文目录规则

`书籍/<学科>/<作者>/<资料性质>/<文档>.md`

所有目录名称均使用中文。原文件名和原始来源路径保留在目录索引中，不修改正文语义。
