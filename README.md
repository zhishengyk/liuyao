# 书籍语料归档

本分支保存六爻及相关术数资料的整理归档。原始快照冻结在 `books-archive-raw-20260914`。

## 目录

- `books/`: canonical 正文，供人工阅读与后续检索构建使用。
- `variants/`: 同题不同来源或不同格式的完整正文版本，不参与默认检索。
- `collections/`: 大型外部合集，目前主要是南怀瑾 CHM 转换稿。
- `support/`: OCR 图片文字和图像转换附件。
- `quarantine/`: 排盘软件、网页支持文件等非正文资料。
- `archive_meta/`: 压缩包入口、复用入口、旧索引、转换校验资料。
- `catalog/`: 全量来源映射、canonical 检索清单、重复组和阅读索引。
